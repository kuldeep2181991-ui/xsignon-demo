Customer Environment

The customer operates multiple offices, development centres, and support centres across different geographic locations.

Its development centres use a Microsoft cloud environment for their operations. The organisation has deployed multiple Microsoft Windows systems connected to several local Domain Controllers, which are joined to multiple Azure AD environments.

Existing Technology Environment

Development centres across multiple geographic locations
Microsoft cloud environment
Microsoft Windows systems
Multiple local Domain Controllers
Multiple Azure AD environments
Hybrid-joined Windows PCs
Microsoft DevOps applications

The Challenge

The customer identified the following requirements as critical:

Enable passwordless authentication for its Microsoft DevOps applications.
Allow teams across global locations to use secure authentication through FIDO2 biometric security keys.
Replace soft authenticators with biometric security keys.
Restrict employees from sharing passwords and other authenticators.
Enable employees to use any Hybrid-joined PC to log in and access their assigned enterprise applications.

The XSignOn Solution

XSignOn helped the customer conduct a rapid proof of concept addressing its authentication and access requirements.

Following the successful proof of concept, XSignOn rolled out its FIDO2 biometric authentication solution across the customer’s environment.

Solution Implementation

01

ThinC-AUTH Biometric Security Keys

XSignOn supplied Ensurity’s FIDO2-certified ThinC-AUTH Biometric Security Keys.

The customer’s administrators were supported in:

  • Configuring the biometric security keys
  • Registering user fingerprints
  • Configuring the PIN fallback option
  • Preparing the keys for employee authentication
02

Windows 10 FIDO2 Configuration

XSignOn supported the customer in configuring its Windows 10 devices to enable FIDO2 authentication.

This allowed employees to use the biometric security keys within the organisation’s Microsoft-based technology environment.

03

Microsoft Intune Device Management

XSignOn demonstrated and supported the management of the customer’s Windows 10 devices through Microsoft Intune.

This enabled the customer’s administrators to centrally manage the devices used across its distributed development centres and offices.

04

Hybrid Environment Configuration

XSignOn worked with the customer to configure its Hybrid Active Directory environment to support biometric and passwordless authentication across Hybrid-joined devices.

The configuration connected the customer’s:

  • Local Domain Controllers
  • Azure AD environments
  • Hybrid-joined Windows systems
  • Microsoft DevOps applications
  • ThinC-AUTH biometric security keys

Solution Capabilities

The implemented solution supported:

Passwordless authentication for Microsoft DevOps applications

FIDO2 biometric authentication

Fingerprint-based user verification

PIN fallback

Authentication across Hybrid-joined Windows PCs

Access to assigned enterprise applications

Windows 10 device configuration

Centralised device management through Microsoft Intune

Integration with local Domain Controllers and multiple Azure AD environments

Secure authentication for teams operating across global locations
